
# Telegram Advanced Caption Bot 🚀

## Features
- Auto caption for photo/video
- Footer / links
- Inline buttons
- Admin system
- Multi-channel support
- Admin Web Panel (Flask)
- Scheduled caption updates (APScheduler)
- MongoDB based storage

## Deploy (Mobile Friendly)
- Railway / Render
- Add environment variables:
  - BOT_TOKEN
  - MONGODB_URI
  - ADMIN_PASSWORD

## Run
```bash
pip install -r requirements.txt
python bot.py
```
